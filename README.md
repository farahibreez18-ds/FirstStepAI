# 🚀 FirstStepAI

An AI-powered career development platform that helps students and job seekers improve their resumes, prepare for interviews, and build skills.

---

## ✨ Features

- 📄 Resume Analyzer
- 🤖 AI Career Coach
- 🎤 Mock Interview
- 📈 Skill Roadmap
- 💼 Job Tracker
- 📚 Learning Hub
- 📊 Career Dashboard

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router
- JavaScript
- HTML5
- CSS3
